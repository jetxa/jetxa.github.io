> 整理自Onenote笔记

* ssh认证方式不需要服务器和客户端配置文件,也不需要启动

使用示例
```bash
rsync -avz /root/test/   -e 'ssh -p 12400'root@202.*.*.*:/root/ 
```
参数说明
- v：详细模式输出
- a：递归方式传输文件
- z：对备份的文件在传输时进行压缩
- delete：删除那些dst中存在而src中没有的文件


列出远程机器的文件列表
```bash
rsync -v rsync://test@202.*.*.*/home/……
``` 
    
    
## 几种常用方式
- `rsync -avz /data /backup` 把本地data目录同步到backup目录
- `rsync -avz /data test@ip` 把本地同步到test服务器上
- `rsync -avz test@ip /data` 把服务器文件拉取到本地

## 示例
从ip地址上拖下文件
```bash
rsync -avz --delete -e "ssh -p 12400" "root@202.*.*.*:~/Documents/Mendeley\ Desktop/" ./Paper/
```
