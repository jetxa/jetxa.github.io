在使用LLM进行文本生成时，重复惩罚系数（repetition penalty）是一个重要的参数，用于控制生成文本中的重复内容。合理设置重复惩罚系数可以显著提升生成文本的多样性和质量。

在vLLM接口中，有三个参数与重复惩罚相关：

- `presence_penalty`: Float that penalizes new tokens based on whether they appear in the generated text so far. Values > 0 encourage the model to use new tokens, while values < 0 encourage the model to repeat tokens.
- `frequency_penalty`: Float that penalizes new tokens based on their frequency in the generated text so far. Values > 0 encourage the model to use new tokens, while values < 0 encourage the model to repeat tokens.
- `repetition_penalty`:  Float that penalizes new tokens based on whether they appear in the prompt and the generated text so far. Values > 1 encourage the model to use new tokens, while values < 1 encourage the model to repeat tokens.

## presence_penalty
惩罚出现过的token, 无论出现过几次

$$logit'(t) = logit(t) - presence\_penalty \times \mathbf{1}_{t \in \text{generated tokens}}$$

value取值范围: 默认值`value=0`，`value > 0` 表示惩罚出现过的token，鼓励使用新词；`value < 0` 表示鼓励生成已有的token

## frequency_penalty
惩罚出现过的token, 根据出现的**频率**进行惩罚

公式：$$logit'(t) = logit(t) - frequency\_penalty \times count(t)$$

value取值范围: 默认值`value=0`，`value > 0` 表示惩罚频繁出现的token，鼓励使用新词；`value < 0` 表示鼓励生成已有的token

## repetition_penalty
直接调整模型的logits

$$logit'(t) = \begin{cases}
logit(t) \times \frac{1}{repetition\_penalty}, & t \in \text{generated tokens}\ and\ \text{if } logit(t) < 0 \\
logit(t) \times repetition\_penalty, & t \in \text{generated tokens}\ and\ \text{if } logit(t) > 0
\end{cases}$$

value取值范围: 默认值`value=1`，`value > 1` 表示惩罚出现过的token，鼓励使用新词；`value < 1` 表示鼓励生成已有的token
